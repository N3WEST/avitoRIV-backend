# Avito RIV Backend


## Выдать Premium вручную администратором

1. Убедись, что зависимости установлены (`pip install -r requirements.txt`) и настроен `.env` с тем же `DATABASE_URL`, который использует API.
2. Открой `premium_ids.txt` и впиши Telegram ID каждого пользователя — по одному числовому ID на строку. Строки с `#` являются комментариями.
3. Запусти из папки backend: `python grant_premium.py`. Скрипт создаст пользователя, если его ещё нет, и установит план `premium` на 30 дней.
4. Для другого срока добавь в `.env` `ADMIN_PREMIUM_DAYS=90` (например, на 90 дней).

Выдача делается локальным скриптом, а не публичным HTTP endpoint, чтобы посторонние не могли назначать себе Premium. После запуска скрипт можно запускать повторно; срок будет отсчитываться заново от момента запуска. Убедись, что `DATABASE_URL` совпадает с настройкой работающего сервера.

Тариф `premium` даёт до 20 активных поисков, каждый сроком до 30 дней.


## Если создание поиска не работает

Парсер открывает ссылку на объявление через Playwright. Для production рекомендуем задать `BROWSERLESS_TOKEN` и при необходимости `BROWSERLESS_ENDPOINT` в Environment переменных хостинга. Без Browserless код попробует локальный Chromium; на сервере для этого нужно установить браузер: `playwright install chromium` (на Linux дополнительно могут потребоваться системные зависимости).

Если API возвращает 502, открой логи сервиса: теперь там есть причина ошибки парсера. Ссылка должна вести на конкретное объявление Avito, доступное без авторизации.
